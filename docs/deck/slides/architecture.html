(Architecture) Everything is a module behind one REST API. The pipeline is the story: discover what cryptography exists, assess it against NIST IR 8547 and Mosca's shelf-life rule, plan the migration in three waves, apply the safe changes automatically, and verify with a second scan. An algorithm registry tags every algorithm with family, type, FIPS standard and quantum status, so adding a new algorithm (for example FN-DSA when FIPS 206 is final) is a data change, which is what crypto-agility means. We only call vetted libraries: the OpenSSL 3.5 command line and Python cryptography.
