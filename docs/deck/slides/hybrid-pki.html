An attacker who records this must break X25519 and ML-KEM to read it. Tick Tamper to show the GCM tag rejecting a changed ciphertext. Then run the three policy tests. For PKI, run the dual-certificate demo: the same server hands an old client an ECDSA certificate and a new client an ML-DSA-65 certificate. NIST has said the 2035 disallowance was not meant to apply to hybrids that pair an approved PQC algorithm with a classical one, which is why hybrid is our default.
